Impression locale

Imprimer sur une jet d'encre Epson depuis Android, sans appli Epson et sans passer par Internet.

Télécharger l'APK Code source

Android 8 ou plus récent · gratuit et libre (GPL) · projet indépendant, sans lien avec Epson.

Le principe

Comme Epson Print Enabler

Un plug-in à installer une fois : l'imprimante apparaît ensuite dans le menu Imprimer de toutes les applis.

Vos documents restent chez vous

Les pages sont converties sur le téléphone et envoyées directement à l'imprimante par le Wi-Fi. Pas de compte, pas de statistiques, pas de serveur.

Mises à jour

Une fois par jour au plus, l'appli regarde la dernière version sur GitHub (rien n'est envoyé) et vous prévient par une notification.

Trouvée automatiquement

L'imprimante est détectée sur le réseau local. Sinon, on peut saisir son adresse IP.

Mon imprimante est-elle compatible ?

Il faut une jet d'encre Epson connectée au Wi-Fi qui comprend le langage ESC/P-R (617 modèles du pilote Linux officiel d'Epson). Tapez votre modèle :

    Non compatibles : modèles récents qui ne parlent que l'ESC/P-R2, laser Epson, imprimantes uniquement en USB. Testé en conditions réelles sur une EcoTank ET-2600 ; les autres modèles utilisent le même langage mais n'ont pas été essayés — dites-nous si ça marche chez vous.

    Installation

    1. Sur le téléphone, téléchargez ImpressionLocale.apk et ouvrez-le. Android demande d'autoriser l'installation depuis le navigateur : acceptez pour cette fois.
    2. Paramètres > Appareils connectés > Préférences de connexion > Impression : vérifiez que « Impression locale » est activé.
    3. Ouvrez l'appli « Impression locale », acceptez les notifications (pour les mises à jour) et touchez Imprimer une page de test.
    4. Ensuite, dans n'importe quelle appli : Partager ou ⋮ > Imprimer.

    Vous pouvez ensuite désinstaller Epson Print Enabler / Epson iPrint pour n'avoir qu'une entrée par imprimante.

    Limites

    • Qualité normale (360 ppp) sur papier ordinaire ; pas de sans-bordure, pas de recto verso, pas de niveaux d'encre.
    • Si le Wi-Fi coupe en pleine impression, l'imprimante peut rester bloquée (voyant qui clignote) : éteignez-la puis rallumez-la.
